## Reproduce iteration 2

From `name-that-llm/`, using the downloaded data:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r runtime-requirements.txt
.venv/bin/python -c "import pandas as pd; pd.read_parquet('data/sample_submission.parquet').to_csv('data/sample_submission.csv', index=False)"
.venv/bin/python scripts/01_eda.py --data-dir data
OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 MKL_NUM_THREADS=2 .venv/bin/python -u scripts/02_baseline_tfidf.py --data-dir data --model lr --c-grid 0.5,1,2,4 --folds 5 --seed 42
.venv/bin/python scripts/04_make_submission.py --data-dir data --inputs outputs/artifacts/b1_lr_test_proba.csv --output submission/submission.csv
.venv/bin/python scripts/05_validate_submission.py --data-dir data submission/submission.csv
```

The old `make_candidate_submissions.sh` also invokes baseline 2, which remains unvalidated; use the commands above for this iteration. Results append to EXPERIMENTS.md and RESULTS.md; large artifacts and logs stay in ignored `outputs/`.
